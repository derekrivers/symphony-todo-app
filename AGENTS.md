# AGENTS

This repository treats `AGENTS.md` as a short map and entry point for agent workflows.
It is intentionally concise and points to deeper knowledge in `docs/`.

## Core repository guide

- `docs/` — source of truth for design, plans, architecture, and reliability guidance.
- `ARCHITECTURE.md` — top-level architecture map, domain boundaries, and allowed dependency directions.
- `README.md` — project overview and onboarding summary.
- `src/` — application implementation scaffold following explicit domain layering.

## Key agent entry points

- `docs/DESIGN.md` — system design principles and major decisions.
- `docs/FRONTEND.md` — front-end architecture and UI expectations.
- `docs/QUALITY_SCORE.md` — quality grading and review guidance.
- `docs/SECURITY.md` — security requirements and guardrails.
- `docs/product-specs/react-todo-app.md` — the main product and architecture specification for the React Todo app.

## Workflow guidance

Agents should use this file to locate the current product intent and then follow the structured docs in `docs/` for deeper context.
