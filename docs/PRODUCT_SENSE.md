# Product Sense

This application is a lightweight productivity tool designed for users who want a simple, modern task manager without the overhead of a full project management system.

The core value proposition is clarity and speed: users can add tasks quickly, organise them with categories and priorities, track progress, and return later to find their work preserved.

The target users are developers, students, freelancers, household managers, and anyone who needs a focused daily task list.

Success is measured by:

- Fast task creation and completion.
- Clear visual separation between active and completed work.
- Consistent local persistence between sessions.
- Responsive behavior across desktop and mobile.
- A scalable architecture that makes future extensions straightforward.

See the detailed product specification in `docs/product-specs/react-todo-app.md`.
